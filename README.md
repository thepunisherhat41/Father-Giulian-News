# Father Giulian News

Hub pessoal diário de conhecimento, atualidades, gravidez, paternidade, mobilidade, viagens, finanças, tecnologia e segurança.

## Objetivo

Uma aplicação mobile-first hospedável na Vercel que organiza conteúdo por temas, mantém histórico, permite favoritar e facilita compartilhar apenas cards selecionados no WhatsApp.

## Gestação

A aplicação usa como data provável do parto (DPP) **11/04/2027** e calcula dinamicamente a idade gestacional a partir dessa referência.

## Princípios de conteúdo

- Conteúdo médico e de gravidez deve priorizar fontes oficiais e científicas.
- Paternidade deve focar presença, cuidado, segurança, vínculo e apoio à mãe, evitando promessas de fórmula perfeita.
- Política deve separar fato, declaração, previsão e interpretação.
- Preços, veículos, viagens, vistos, clima, finanças e notícias devem ser tratados como dados temporais e pesquisados antes de publicação.
- Segurança e tecnologia são áreas distintas.

## Stack planejada

- Next.js
- TypeScript
- Vercel
- PWA/mobile-first
- Conteúdo estruturado por categorias
- Compartilhamento via Web Share API / WhatsApp
